# Template Folder

Place your template images in this folder.

Supported file types:

- `.png`
- `.jpg`
- `.jpeg`
- `.svg`
- `.webp`

How it works:

- The backend scans this folder automatically.
- Files here appear in the admin template importer.
- From the app, you can turn any of these files into a reusable template.
- The image can be used as the template thumbnail and optionally as the center logo.
